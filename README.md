Transaction Management System

A full-stack web application to track income and expenses built with MongoDB, Node.js, Express.js and React.js.

Features
- Add income and expense transactions
- Real-time balance, income and expense summary
- Category-based transaction tagging
- Search transactions by description or category
- Delete any transaction

Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **ODM:** Mongoose

Prerequisites
- Node.js
- MongoDB Community Server

 Setup & Run

1. Start MongoDB Service
Make sure MongoDB is running on your system.

2. Backend
cd backend
npm install
node server.js

3. Frontend
cd frontend
npm install
npm start
